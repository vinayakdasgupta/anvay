What to do

  • Each file must be under 1 MB. Check your largest files and split or trim them if needed.
  • The total submission cannot exceed 5 MB across all files.
  • If you are working with a large corpus, consider processing it in smaller batches.
  • Only plain text (.txt) files are accepted — binary or rich-text formats are not supported.
{% elif error.code == 429 %}

Why this happened

  • anvay limits submissions to 6 per minute and 30 per hour per IP address to keep the server available for everyone.
  • Wait a minute or two, then try again.
  • If you need to run many jobs in quick succession, consider running anvay locally — it is open source and straightforward to install.

Possible reasons

  • If you followed a link to a result page, the job has likely expired. Results are kept for 2 hours after processing.
  • Check that the URL is correct and has not been truncated.
  • If you believe this is a bug, please contact us.
